# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-08

### Added
- Initial release of FileForge.
- Modern responsive HTML/CSS/JS frontend supporting dark, light, and system themes.
- Grid and list directory views with breadcrumbs and instant search.
- Multi-file drag and drop uploads and streaming downloads.
- HTTP Range support for media seeking and streaming.
- Image, text, media, and PDF previews.
- Zip archiving for folders and multi-select downloads.
- Path traversal and symlink escape security validation.
- SQLite-backed authentication sessions and temporary share links.
- Command-line interface with custom root paths, host, port, and password options.
