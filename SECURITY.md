# Security Policy

## Security Model

FileForge is built with strict path validation and isolation rules to ensure files outside the configured storage root cannot be accessed, modified, or downloaded.

### Measures Implemented:
1. **Path Traversal Prevention**: Absolute path resolution (`Path.resolve()`) verifies that all targets remain sub-paths of the root. `../` traversal attempts are rejected.
2. **Symlink Escape Prevention**: Symlinks pointing outside the storage root are identified and blocked.
3. **Execution Safety**: Uploaded files are served with content disposition / octet-stream mime types. Server never executes uploaded files.
4. **ZIP Extraction / Creation Safety**: Archives generated by FileForge write only sanitized relative arcnames.
5. **No Password/Token Leakage**: Passwords are saved with PBKDF2 salt-hashes; raw passwords/tokens are never logged.

## Reporting a Vulnerability

If you discover a security issue, please email security@fileforge.local or open a confidential report.
